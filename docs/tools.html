Every tool is built natively in C# RhinoCommon for instantaneous viewport manipulation, IBC/EN building code compliance, and automated manifold Boolean cuts.

Showing 15 of 15 Parametric Generators

Parametric Modern Door Generator

ArchDoor

Creates modern single-leaf, double-leaf, unequal, pivot, and sliding doors with customizable jamb frames, casing trim, door panels, glass lites, threshold profiles, and modern handles.

// WORKFLOW TUTORIAL:
  1. Type ArchDoor in the Rhino command line or click the door icon on the Shalik toolbar.
  2. Click two points in your viewport to define the door opening width and orientation.
  3. Adjust leaf typology (Single / Double / Pivot / Sliding), swing angle, frame width, and glass inserts in the live dialog.
  4. Click Create Door to bake geometry onto organized DOOR sub-layers.

Parametric Window Generator

ArchWindow

Generates fixed picture, casement, horizontal sliding, awning, hopper, and bifold windows with customizable mullion grids, sill overhangs, glass panes, and transoms.

// WORKFLOW TUTORIAL:
  1. Type ArchWindow in Rhino.
  2. Pick the two baseline points defining the window opening width.
  3. Choose window style (Fixed, Casement, Sliding), specify mullion divisions, sill profile, and frame depth.
  4. Press Create Window to bake geometry with assigned materials.

Auto Wall Cut & Element Insertion

ArchDoorInWall ArchWindowInWall

Automates wall penetrations by cutting precise rectangular openings through Rhino polysurface solid walls and inserting the parametric door or window assembly simultaneously.

// WORKFLOW TUTORIAL:
  1. Select the target wall polysurface when prompted.
  2. Click the baseline insertion point on the wall face.
  3. Specify door/window dimensions and sill height.
  4. Shalik automatically cuts the wall solid and places the parametric frame perfectly flush.

Architectural Staircase Generator

ArchStair

Engineers 10 distinct staircase structural systems: Sawtooth, Closed Housed Stringer, Central Mono-Stringer, Cantilevered Floating Treads, Open Double-Stringer, Spiral, and Dogleg 180° stairs with automatic IBC/EN code riser-tread proportions.

// WORKFLOW TUTORIAL:
  1. Run ArchStair.
  2. Input floor-to-floor total height (e.g. 10'-0" or 3000 mm).
  3. Select structural typology (e.g. Central Mono-Stringer, Floating, or Dogleg).
  4. Adjust riser height and tread run (the dialog warns if outside code compliance).
  5. Click Generate Staircase (optionally check "Add Railing" for automatic matching balustrades).

Guardrail & Balustrade Generator

ArchRailing

Generates 10 guardrail and balustrade types: Frameless glass shoe, glass standoff pins, post & clamp, multi-strand stainless cable rail, horizontal pipe rods, and vertical square balusters.

// WORKFLOW TUTORIAL:
  1. Run ArchRailing.
  2. Select a baseline path curve or pick two points along a slab edge or balcony.
  3. Select railing system (e.g. Frameless Glass Shoe or Cable Rail).
  4. Adjust handrail height (42" / 1067mm standard), post spacing, and glass panel thickness.
  5. Click Create Railing.

Multi-Layer Architectural Wall

ArchWall

Parametric multi-layered exterior and interior walls with polyline drafting, clean mitered corners, and layer detailing (structural core, rigid insulation, air cavity, brick/cladding veneer, interior gypsum drywall).

// WORKFLOW TUTORIAL:
  1. Type ArchWall and draw the wall centerline polyline in top viewport.
  2. Select wall thickness, height, and layer assembly configuration.
  3. Press Enter to generate cleanly mitered, solid architectural walls.

Curtain Wall Facade Generator

ArchCurtainWall

Commercial facade system generator with multi-floor grids, vertical mullions, horizontal transoms, spandrel panels, insulated glass units, and interactive baseline alignment.

// WORKFLOW TUTORIAL:
  1. Type ArchCurtainWall and pick the facade baseline curve.
  2. Set floor-to-floor count, bay grid width, mullion profile dimensions, and spandrel height.
  3. Preview the dynamic facade in 3D and press Create Facade.

Commercial Escalator & Moving Walkway

ArchEscalator

Parametric commercial escalators (30° / 35° incline) and horizontal moving walkways with structural steel trusses, step treads, comb plates, and transparent glass balustrades.

// WORKFLOW TUTORIAL:
  1. Type ArchEscalator.
  2. Specify floor-to-floor rise height and step tread width (800mm or 1000mm standard).
  3. Select balustrade type (Glass / Solid Panel) and lighting profile.
  4. Click Create Escalator to place the complete structural assembly.

Structural Truss & 3D Spaceframe

ArchTruss ArchSpaceTruss

Generates Pratt, Warren, Howe, and X-braced trusses (solid 3D structural tubes or 2D planar centerline drafting lines) as well as double-layer pyramid grid 3D space frames with spherical MERO ball nodes.

// WORKFLOW TUTORIAL:
  1. Run ArchTruss for planar/3D trusses or ArchSpaceTruss for roof spaceframes.
  2. Pick span baseline points or select a bounding roof surface.
  3. Configure top chord, bottom chord, diagonal web angles, and node sizes.
  4. Bake onto STRUCTURAL sub-layers.

Pitched Roof & Timber/Steel Framing

ArchPitchRoof

Creates gable, hip, shed, and gambrel roofs complete with 6 tile/cladding types (Spanish clay tiles, standing seam metal, shingles) and structural rafters, purlins, and fascia boards.

// WORKFLOW TUTORIAL:
  1. Type ArchPitchRoof and pick the building footprint polygon.
  2. Select roof shape (Gable / Hip / Shed), set roof pitch angle and eave overhang.
  3. Choose covering material and framing rafter dimensions.
  4. Click Generate Roof.

Architectural Louver & Brise-Soleil

ArchLouver

Parametric vertical and horizontal solar shading fins, airfoil blades, and brise-soleil facades with customizable blade pitch and tilt angles.

// WORKFLOW TUTORIAL:
  1. Type ArchLouver and select opening boundary curve.
  2. Choose fin orientation (Horizontal / Vertical) and blade profile (Airfoil / Box / Slanted).
  3. Set solar blade angle and spacing, then bake.

Decorative Security Grill & Privacy Screen

ArchGrill

Generates window security grills, privacy screens, and Islamic/modern geometric mashrabiya panels across 12 distinct parametric patterns.

// WORKFLOW TUTORIAL:
  1. Run ArchGrill and pick the opening perimeter.
  2. Select pattern typology from the dropdown preview.
  3. Specify bar thickness, pattern repetition frequency, and frame profile.
  4. Bake onto GRILL layers.

Parametric Window Blinds & Shades

ArchBlind

Creates Venetian horizontal blinds, vertical slat blinds, roller fabric shades, and matchstick bamboo blinds with rotation angles.

// WORKFLOW TUTORIAL:
  1. Run ArchBlind and pick the window frame head.
  2. Select shade typology (Venetian / Vertical / Roller).
  3. Adjust slat tilt angle (0° to 90°) and drop length.
  4. Click Generate Blinds.

Urban Road Corridor & Utility Poles

ArchRoad ArchElectricPole

Parametric urban street generator with asphalt lanes, concrete curbs, sidewalks, crosswalk striping, street lighting poles, and electric utility power poles with overhead power lines.

// WORKFLOW TUTORIAL:
  1. Type ArchRoad and draw the center alignment curve.
  2. Set road width, lane count, sidewalk dimensions, and lighting pole intervals.
  3. Generate the complete parametric urban corridor.

Landscape Vegetation & Forest Scatter

ArchTree ArrayTree

Parametric 3D architectural trees (Hardwood, Softwood, Palm) with foliage density control and linear street avenue or surface random forest scattering.

// WORKFLOW TUTORIAL:
  1. Run ArchTree for individual trees or ArrayTree for site distribution.
  2. Select tree species and canopy height.
  3. Pick point positions or select boundary path curve to scatter.
