02 // ARCHITECTURAL ENGINE

Next-Gen Modeling Capabilities

Built for architectural practitioners who demand speed, code compliance, and parametric flexibility without the complexity of Grasshopper.

Real-Time Viewport Conduits

Interact with shaded and wireframe 3D previews directly in your active Rhino viewport while adjusting sliders before committing geometry to the document.

Double-Click to Edit

Need to modify a door width or change a stair tread depth later? Simply double-click any placed element in your viewport to reopen its parameters dialog instantly.

1-Click Wall Cut Automation

ArchDoorInWall and ArchWindowInWall automatically cut clean solid rectangular openings through solid polysurface walls without Boolean failures.

Parametric Presets

Save and reuse custom architectural styles (frames, profiles, materials) as portable JSON presets to maintain design consistency across studio projects.

Automatic Layer Organization

Elements bake cleanly onto standardized sub-layers (FRAME, PANEL, GLASS, HARDWARE, CORE) grouped by component for instant rendering assignments.

Dynamic Unit Intelligence

Seamlessly adapts to your active document units: Imperial (Inches, Feet) or Metric (Millimeters, Centimeters, Meters) with intelligent scale conversions.
